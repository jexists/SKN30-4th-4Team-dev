# data — 수집한 데이터

크롤링·수집한 원본과 전처리 결과를 둡니다. (리뷰·git 추적에서 제외 — `.gitignore`/`.coderabbit.yaml` 참고)

```
data/
├── raw/         # 수집 원본 (법령·판례·등기부 샘플·계약서 템플릿 등)
└── processed/   # 전처리·정제 결과 (청킹 전 단계)
```

> 임베딩·벡터는 **Supabase(pgvector)** 에 적재합니다. 여기(data/)에는 원본·중간 산출물만 둡니다.
> 대용량 파일은 커밋하지 말고 별도 스토리지/링크로 관리하세요.
