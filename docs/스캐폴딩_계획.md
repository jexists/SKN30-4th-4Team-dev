# 스캐폴딩 계획 — 결정 사항 & 할 일

[SKN30-3rd-4Team](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN30-3rd-4Team) 고도화 프로젝트의 초기 구조·기술 결정 기록.

## ✅ 정한 것

**구조**
- 모노레포: `backend` / `frontend` / `data` / `docs` / `final`
- 백엔드: FastAPI (uv, Python 3.12), 모듈형(api·core·db·models·schemas·services·pipeline)
- 프론트: React + Vite + TypeScript, 컴포넌트별 폴더, CSS Modules(SCSS), react-router
- 크로스플랫폼: Mac·Windows (.gitattributes LF 정규화)

**데이터·인증**
- DB: Supabase Postgres + pgvector, SQLAlchemy ORM 하이브리드, 로컬 SQLite 폴백
- 인증: Supabase Auth(소셜 로그인), 백엔드는 JWT 검증만, Redis 불필요
- 파이프라인: 청킹·임베딩 로직 `services/`, 오프라인 배치 `pipeline/`

**규약**
- API 응답: 표준 봉투 `ApiResponse[T]` (success·code·message·data·error)
- API 버전: `/api/v1`
- 코드 품질: ruff(백) + ESLint·Prettier(프론트)
- 테스트: pytest + Vitest, TDD 권장(강제 X)
- 협업: develop+main, 한국어 Conventional Commits, .coderabbit.yaml, 중첩 CLAUDE.md, Discord PR 알림(`.github/workflows`, 제목 "4차")
- Docker: 기본 제공(선택 실행)

**화면(사이트맵, 현재 텍스트 스텁)**
- `/`, `/analyze`(+`/analyze/:id`), `/chat`(+`/chat/:id`), `/login`, `/onboarding`, `/mypage`, `/terms`, `/privacy`

## 🔜 추가로 할 일
- ERD 설계 → `docs/ERD.md` → `models/` + Alembic
- RAG 구현: 청킹·임베딩·검색(`services/`), 배치 색인(`pipeline/`), 임베딩·LLM 모델 선택
- 화면 실제 디자인·기능 (스텁 → 구현)
- Supabase Auth 실제 연동 (`/login`, `/onboarding`)
- 파일 업로드(등기부·계약서) → Supabase Storage
- `conventions.md` '결정 필요' 채우기: 페이지네이션·업로드·ID전략·인증역할·citation·면책·프롬프트·관찰성
- **회원 탈퇴 후 3일이 지나면 완전 삭제하는 배치 작업 구현 예정** (Scheduler/Cron → chats·contracts·files·notifications 삭제 후 `app_user` Hard Delete) — 정책은 [`회원탈퇴.md`](./회원탈퇴.md)
- (선택) CI 테스트 자동화, 기본 UI 컴포넌트, TanStack Query/폼

## 🗑️ 나중에 지우거나 대체할 것 (데모)
- `/api/v1/hello` 엔드포인트 (데모 인사)
- 페이지 스텁의 "화면 이름 텍스트" (→ 실제 화면 구현으로 대체)
- `services/ingestion`·`retrieval` 빈 스텁 (→ 실제 로직으로 대체)
- SQLite 폴백 (→ Supabase 연결 시 제거)
- (선택) `HealthStatus` — 연결 확인용이라 불필요하면 제거 가능
- ※ **`health.py`(헬스체크)는 유지** — 표준 영구 엔드포인트, 삭제하지 않음

## ⭐ 중요 포인트
- `models`(ERD·DB) ↔ `schemas`(Pydantic·API) **분리**
- Supabase = Postgres 호스팅, SQLAlchemy = ORM (**둘 다 씀**)
- 페이지 스텁은 텍스트만, 연결 확인은 레이아웃의 `HealthStatus`
- 데모(hello·스텁) vs 영구(health·core) 구분
